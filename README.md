# 指標1：単元目標準拠ルーブリック評価（主指標）

- **評価枠組み**：単元目標準拠ルーブリック（要素別 A/B/C，総合 S/A/B/C）
- **評価実行日**：2026年5月19日

## 1.1 使用モデル

| プロバイダ | モデル名 | 役割 |
|---|---|---|
| OpenAI | `gpt-5.5` | Judge 1 |
| Anthropic | `claude-opus-4-7` | Judge 2 |
| Google | `gemini-3.1-pro-preview` | Judge 3 |

3モデルによる Panel of LLM Evaluators 構成（Verga et al., 2024）を採用．異なる開発者・アーキテクチャの独立評価により，モデル内バイアスへの頑健性を担保する．

## 1.2 APIパラメータ（実行時の実値）

| パラメータ | OpenAI `gpt-5.5` | Anthropic `claude-opus-4-7` | Google `gemini-3.1-pro-preview` |
|---|---|---|---|
| temperature | 指定なし（デフォルト=1.0）※1 | 指定なし（デフォルト）※2 | **0.2** |
| seed | **2026** | 非対応 | 非対応 |
| 出力フォーマット指定 | `response_format={"type": "json_object"}` | 指定なし（プロンプト指示のみ） | `response_mime_type="application/json"` |
| 最大トークン | `max_completion_tokens=2000` | `max_tokens=1500` | `max_output_tokens=2000` |
| 同一サンプル採点回数 (`N_RUNS`) | **3**（Self-consistency） | **3** | **3** |

- ※1：GPT-5 系は API 仕様上 `temperature` 指定が無効化されているため，デフォルト値（=1）で実行．
- ※2：Claude Opus 4.7 でも `temperature` 指定が deprecated のためデフォルトで実行．
- 上記の温度差については，**同一サンプル3回採点の最頻値（Self-consistency, Wang et al., 2023）**を採用することで揺らぎを集約し，モデル間で同等の安定性を確保した．

### 共通設定

- リトライ：`tenacity` で最大3回，指数バックオフ（multiplier=2, min=2s, max=20s）
- 並列度：ThreadPoolExecutor で最大8並列
- 採点総数：148サンプル × 3モデル × 3回 = **1,332回採点**

## 1.3 システムプロンプト（全LLM共通）

````
あなたは小学校国語科の指導経験を持つ評価専門家です．小学校4年生の児童が『ごんぎつね』（物語文）の各場面の学習で記述した振り返り文を，単元目標準拠ルーブリック（要素別A/B/C，総合S/A/B/C）で評価してください．

【本実践における中核目標（展開部）】
本文の根拠を示しながら，登場人物の心情や情景を読み取り，他者の考えを踏まえて自分なりの考えを深める．

【評価の3要素】
- 要素A（本文根拠の明示）：本文中の登場人物の行動・描写・記述を具体的に引用または参照しているか
- 要素B（心情・情景の読み取り）：登場人物の気持ちの変化・性格・情景を場面の移り変わりと結び付けて読み取れているか
- 要素C（他者参照を踏まえた自己の解釈の統合）：要素A・Bを踏まえ，他者の考えを取り込みながら自分なりの解釈を論理的・関係的に構成しているか．他者参照の影響は明示的（「友達の意見で」等）・黙示的（初発の感想からの変化）の両方を評価対象とする．

【要素別判定基準】
■ 要素A
A：本文中の具体的な行動・描写・記述を引用または参照（複数または1つでも具体的）
B：本文根拠の言及はあるが具体性が乏しいか1要素のみ
C：本文根拠の言及がない，または無関係な記述
■ 要素B
A：心情を本文根拠と結び付け，場面の移り変わりとの関連も示す
B：心情の読み取りはあるが場面の結び付きが弱いか単一側面のみ
C：心情の読み取りが表層的（「かわいそう」のみ）か未記述
■ 要素C
A：要素A・Bを統合し，他者参照を踏まえた解釈の更新が明示的または黙示的に確認できる
B：要素A・Bが並列的．他者参照への言及はあるが取り込みが弱い，または他者参照への言及自体がない
C：活動の感想のみ，または無関係な記述に終始

【集約ルール（要素別→暫定総合判定）】
1. 3要素全てA → 暫定A
2. 2要素がA，1要素がB → 暫定A
3. 1要素以上がCを含む場合は最高でも総合B
4. 2要素以上がC → 総合C
5. それ以外 → 総合B

【Sへの昇格判定】
暫定総合判定がAの場合に限り，以下のいずれかが認められれば総合S：
- 抽象化：他作品・自己経験・人間関係の真実への一般化
- 批判的考察：登場人物の行動・心情への批判的視点
- 作品全体の主題への到達（すれ違い・後悔・贖罪等）
認められない場合 → 総合A確定

【留意事項】
- 文字数の多少は判定基準ではない
- 個人的体験への過度な脱線は要素C加点に含めない
- 「先生」「みんな」のような曖昧な参照は要素Aの本文根拠としては弱い
- 漢字・誤字脱字は判定対象外

【出力フォーマット（JSON形式）】
必ず以下のJSON形式で出力してください．他の説明文や前置きは不要です．

{
  "要素A_本文根拠": "A" or "B" or "C",
  "要素B_心情読み取り": "A" or "B" or "C",
  "要素C_解釈統合": "A" or "B" or "C",
  "暫定総合判定": "A" or "B" or "C",
  "S昇格条件_該当有無": "あり" or "なし",
  "総合判定": "S" or "A" or "B" or "C",
  "判定理由": "50字以内で簡潔に判定根拠を述べる"
}
````

> 補足：Google Gemini ではシステムプロンプトとユーザメッセージを分離せず，1つの `contents` として `システムプロンプト + "\n\n" + ユーザメッセージ` の形で送信した．

## 1.6 Self-consistency 集約処理

同一サンプルに対する3回採点を以下の2段階で集約した（Wang et al., 2023）．

### モデル内集約（3回採点 → 1モデル判定）

```python
from collections import Counter

def aggregate_within_model(judgments_3runs):
    """3回採点 → 最頻値（2回以上一致）または順序尺度の中央値."""
    valid = [j for j in judgments_3runs if j in ("S", "A", "B", "C")]
    if not valid:
        return None
    counts = Counter(valid)
    most_common = counts.most_common()
    if most_common[0][1] >= 2:
        return most_common[0][0]
    # 全て異なる場合は順序尺度で中央値（C=1, B=2, A=3, S=4）
    rank_map = {"C": 1, "B": 2, "A": 3, "S": 4}
    rev_map  = {v: k for k, v in rank_map.items()}
    ranks = sorted(rank_map[s] for s in valid)
    return rev_map[ranks[len(ranks) // 2]]
```

### モデル間集約（3モデル判定 → 最終判定）

```python
def aggregate_across_models(judgments_3models):
    """3モデルの判定 → 順序尺度の中央値（最終採用値）."""
    valid = [j for j in judgments_3models if j in ("S", "A", "B", "C")]
    if not valid:
        return None
    rank_map = {"C": 1, "B": 2, "A": 3, "S": 4}
    rev_map  = {v: k for k, v in rank_map.items()}
    ranks = sorted(rank_map[s] for s in valid)
    return rev_map[ranks[len(ranks) // 2]]
```

要素別判定（A/B/C 3段階）についても，同一の方式で「モデル内最頻値 → モデル間中央値」を算出した．

# 指標2：SOLOタクソノミー評価（補助指標）

本論文ではSOLOタクソノミー（Biggs & Collis, 1982）を**補助指標**として用い，単元目標準拠ルーブリックとの対応関係（Spearman *ρ* = .615）から構成概念妥当性を確認している．SOLO評価は本論文の主分析に先行する段階で実施した既存データを再利用する形で組み込んでおり，使用モデルおよびパラメータは主指標のルーブリック評価とは異なる．

- **評価枠組み**：SOLOタクソノミー（Pre-structural〜Extended Abstract の5階層，Level 1〜5）
- **評価実行日**：2026年2月5日

## 2.1 使用モデル

| プロバイダ | モデル名 | 役割 |
|---|---|---|
| OpenAI | `GPT-5.2` | Judge 1 |
| Anthropic | `Claude 4.5 Opus` | Judge 2 |
| Google | `Gemini 3 Pro` | Judge 3 |

3モデルによる独立評価を実施し，モデル間のPearson積率相関係数 *r* = .86 〜 .91 を確認した上で，第一著者による無作為抽出再評価を経て本指標のスコアとして採用した．

## 2.2 APIパラメータ

| パラメータ | 設定値 |
|---|---|
| temperature | **0.7**（全モデル統一） |
| 出力フォーマット | プロンプト指示によるテキスト形式（`【SOLOレベル】`／`【判定理由】`） |
| 採点回数 | 1サンプルにつき1回 |

> SOLO評価は，本論文の主指標であるルーブリック評価より先行する時期に実施したため，Self-consistency（同一サンプル複数回採点）は適用していない．代わりに3モデル間の高い相関（*r* = .86〜.91）と第一著者による抽出再検算をもって信頼性を確認した．

## 2.3 システムプロンプト（全LLM共通）

````
# 命令
あなたは小学校4年生の国語科における評価の専門家です。 以下の【前提条件】と【評価基準】に基づき、提示される児童の振り返り記述を読み、最も適切なSOLOレベル(1〜5)を1つだけ判定してください。

# 前提条件
教材:小学校4年生 国語「ごんぎつね」(新美南吉)
評価の観点:思考・判断・表現
登場人物の気持ちの変化や性格、情景について、場面の移り変わりと結び付けて具体的に想像することができる
学習目標:
登場人物の気持ちの変化を捉える
情景から、人物の様子や気持ちを具体的に想像する
場面と場面を結び付けたり比べたりして、登場人物の気持ちの変化を考える
評価対象:学習後の振り返り記述
評価の重要原則:
物語内容の理解を中心に評価する(登場人物の気持ち、場面の解釈など)
学習活動への言及(「友達の意見を聞いて」「発表できた」など)は、物語理解と結びついている場合のみ評価に含める
学習活動のみの記述は低いレベルと判定する

# 評価基準(SOLOタクソノミー)

| レベル | 名称 | 判定ロジック・特徴 | 実際の児童記述例 |
|---|---|---|---|
| Level 1 | Pre-structural<br>(前構造的) | 記述なし、または意味をなさない<br>・記述がない(空欄)<br>・学習内容と無関係(「楽しかった」「よく分かった」のみ)<br>・極端に短い記述で物語内容に触れていない | 「よく分かった」<br>(空欄) |
| Level 2 | Uni-structural<br>(単一構造的) | 単純な感情語のみ、または学習活動のみ<br>・単一の感情表現のみ<br>・「友達の意見を聞いて」など学習活動への言及のみで物語理解なし<br>・理由や根拠がない | 「ごん気持ちをもっと知りたいておもって」<br>「友達が、私が思っていない事とかを、発表したり、書いていだので、とても楽しかった」 |
| Level 3 | Multi-structural<br>(多構造的) | 複数の要素が列挙されている<br>・感情+学習活動、複数の気づきなど<br>・「〜し」「〜て」などの並列表現<br>・友達の意見と自分の考えの比較があるが、物語理解の深まりは不明確 | 「友達の考えを聞いて、自分と似ていた考えもあれば、少し違う意見もありました。書かれていることからごんがその時に思っていたことも考えることができました。」<br>「自分が思っていない、意見がいっぱい出てきて、面白かったです。友達の考えを見ていると、私が思わなかった考えを書いていて、確かにって思った考えがいっぱいありました。」 |
| Level 4 | Relational<br>(関係構造的) | 因果関係・関連付けが明確<br>・「〜から」「〜ので」「なぜならば」で因果を説明<br>・本文の具体的記述を根拠として示す<br>・場面と気持ちを結び付けている<br>・仮定(「もし〜だったら」)を使った論理的推論 | 「ごんはさみしいからみんなにかまってほしくてイタズラをするのかなと思いました。」<br>「ごんは、兵十に合っていなかったら、寂しかったんじゃないかと思いました。なぜならば、兵十の取った魚をごんが逃がして、そのせいで、兵十のおっかぁが死んだから、申し訳ないと思い、食べ物をたくさん持ってきていたからです。」<br>「ごんがひとりぼっちじゃなて親や友達がいたらごんは寂しい思いをしなかったし人間にイタズラをしてきらわれなかったし自分も兵十の母親もしなかったのでごんはとてもかわいそうだと思った」 |
| Level 5 | Extended Abstract<br>(拡張抽象的) | メタ認知・一般化・概念化を含む<br>・物語理解の変化への言及(「最初は〜と思ったが、〜がわかった」)<br>・複数の視点を統合した新しい解釈<br>・学習方法への気づき+物語理解の深化の両方<br>・物語から得た一般的な教訓や洞察 | 「イタズラをする理由について最初はあまり考えていなかったけど考えてみると色々な発見があった。」<br>「まず、友達の考えを聞いて思ったことは、自分の考えくらいしかごんがイタズラをする根拠がないと思っていたけど、たとえば、ごんはシンプルに人に構って欲しかったから。このような似ているけど違う納得する考えがたくさん出ていました。」<br>「〇〇さんの意見と□□さんの意見でを繋ぎ合わせれば確かにごんは寂しいということがわかりました。また、△△さんの15ページ4行目のほっとしてという意見が私には思いつかなかったので、次回はそういった普段自分が書かないような、文を教科書から読み取ろうと思いました。」 |

# 判定上の注意事項

【重要】学習活動への言及の扱い方
多くの児童が「友達の意見を聞いて」「班で話し合って」などの学習活動に言及します。これらの評価は以下のように判断してください:

- 学習活動のみ → Level 2
  - 例:「友達の意見を聞いて楽しかった」「発表できて安心した」
- 学習活動 + 物語内容の列挙 → Level 3
  - 例:「友達の意見を聞いて、自分と似ていた。ごんの気持ちがわかった」
- 学習活動 + 物語理解の因果的説明 → Level 4
  - 例:「友達の意見を聞いて、ごんは〜だから○○したとわかった」
- 学習活動 + 理解の変化(メタ認知) → Level 5
  - 例:「最初は〜と思ったが、友達の意見で〜という新しい発見があった」

その他の注意点
- 境界判定:Level 3と4の境界は因果表現(「〜から」「〜ので」「なぜならば」)と本文根拠の有無で判断
- 文字数:長さで判断しない(短くても因果関係があればLevel 4)
- 誤字脱字:評価に影響させない
- 迷った場合:低い方のレベルを選択

# Few-shot例(実際の児童記述から)

Level 1の例
記述:「よく分かった」
理由:物語内容に全く触れていない

Level 2の例
記述:「ごん気持ちをもっと知りたいておもって」
理由:単一の感想のみで理由や根拠なし
記述:「友達が、私が思っていない事とかを、発表したり、書いていだので、とても楽しかった」
理由:学習活動への言及のみで物語理解なし

Level 3の例
記述:「友達の考えを聞いて、自分と似ていた考えもあれば、少し違う意見もありました。書かれていることからごんがその時に思っていたことも考えることができました。」
理由:複数要素の列挙だが因果関係は不明確
記述:「自分が思っていない、意見がいっぱい出てきて、面白かったです。友達の考えを見ていると、私が思わなかった考えを書いていて、確かにって思った考えがいっぱいありました。」
理由:学習活動と気づきの列挙だが、具体的な物語理解の深まりは不明

Level 4の例
記述:「ごんはさみしいからみんなにかまってほしくてイタズラをするのかなと思いました。」
理由:「〜から」で因果関係を明示
記述:「ごんは、兵十に合っていなかったら、寂しかったんじゃないかと思いました。なぜならば、兵十の取った魚をごんが逃がして、そのせいで、兵十のおっかぁが死んだから、申し訳ないと思い、食べ物をたくさん持ってきていたからです。」
理由:「なぜならば」で因果関係を説明、本文の出来事を根拠として使用

Level 5の例
記述:「イタズラをする理由について最初はあまり考えていなかったけど考えてみると色々な発見があった。」
理由:自分の理解の変化(メタ認知)を明示
記述:「まず、友達の考えを聞いて思ったことは、自分の考えくらいしかごんがイタズラをする根拠がないと思っていたけど、たとえば、ごんはシンプルに人に構って欲しかったから。このような似ているけど違う納得する考えがたくさん出ていました。」
理由:当初の考えと学習後の気づきの対比(メタ認知)、複数視点の統合

以下の形式で評価結果を出力してください:
【SOLOレベル】: Level [1/2/3/4/5]
【判定理由】
(なぜこのレベルと判定したか、具体的な言語表現に着目して説明)
````

## 2.4 出力データの構造化

LLM出力の `【SOLOレベル】` `【判定理由】` テキスト2項目を，後処理にて `Score`（1〜5の整数）および `Rationale`（理由テキスト）としてCSVに格納した．その後の追加分析として，同一児童のページ間変化（`Key_Change`）および他者参照への言及有無（`Peer_Influence`）を派生指標としてアノテーションした出力を一部モデルで保持している．

論文本文の構成概念妥当性検証（Spearman *ρ* = .615）には `Score` のみを用いている．

# 両指標の対応関係と妥当性・信頼性

論文本文（第4章）にて以下を報告している．

## 単元目標準拠ルーブリック評価の妥当性・信頼性（主指標）

| 指標 | 実測値 | 解釈 |
|---|---|---|
| 第一著者人手評定 vs 3LLM中央値（4段階線形重み付け） | Cohen's *κ*<sub>w</sub> = **.606** | substantial agreement |
| 二値化（A以上 vs B以下）人手 vs LLM | Cohen's *κ* = **.595** | substantial agreement |
| 隣接一致率（人手 vs LLM） | **98.0%** | — |
| 3LLM相互の評価一致度 | ICC(2,3) = **.895** | excellent |
| 3LLM間 Pearson 相関 | *r* = .72〜.87 | — |

妥当性検証は，全148サンプルから SOLO レベルで層化無作為抽出した50サンプル（33.8%）について，第一著者が LLM 分類結果を非開示の状態で独立に再評価した結果に基づく．

## SOLOタクソノミー評価の信頼性（補助指標）

| 指標 | 実測値 |
|---|---|
| 3LLM間 Pearson 積率相関 | *r* = .86〜.91 |
| 第一著者による無作為抽出再検算 | 評価基準と整合することを確認 |

## 構成概念妥当性（ルーブリック × SOLO）

| 指標 | 実測値 |
|---|---|
| 両指標のスピアマン順位相関 | *ρ* = **.615**, *p* < .001（*n* = 143） |

完全一致ではないことから，両指標が「内容妥当性」と「構造的複雑性」という独立した側面を捕捉していることが確認された．
